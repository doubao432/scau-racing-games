# 华农狂飙

- [华农狂飙 V2 · 追风乱斗](https://doubao432.github.io/scau-racing-games/zhuifeng.html)
- [华农狂飙 · 五山战车](https://doubao432.github.io/scau-racing-games/wushan.html)

两个独立的单文件 WebGL2 浏览器游戏；无需安装、无需登录。游戏资源已内嵌。需要支持 WebGL2 的浏览器；手机建议横屏游玩。游戏保持单机模式，发布网页不等于联网多人对战。

游戏设置和记录保存在当前浏览器内，各版本使用独立存档名称。清除浏览器数据会清除本地记录。

非官方校园主题作品，虚构封闭赛道，请勿模仿危险驾驶。
